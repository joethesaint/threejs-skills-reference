# Three.js Skills Reference Archive

A personal, source-preserving archive of the Markdown documentation used by the Three.js skills installed for my projects.

This repository is public for now and can be switched to private later without changing its contents. It keeps the documentation in its original directory layout so that links between each skill guide and its reference notes continue to work.

## Contents

- **Impertio Studio — Three.js Claude Skill Package:** 119 Markdown files, including all skills, agent instructions, and project documentation
- **Majid Manzarpour — threejs-game-skills:** 28 Markdown files

See [SOURCES.md](SOURCES.md) for the original repositories, exact commits, and licenses.

## Layout

```
sources/
  impertio-threejs-claude-skill-package/skills/
  majidmanzarpour-threejs-game-skills/skills/
LICENSES/
```

Each source remains subject to its original MIT license, included in `LICENSES/`. This archive records documentation from the pinned commits listed in [SOURCES.md]; it is not a replacement for the upstream projects.
